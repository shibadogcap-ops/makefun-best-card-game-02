AETHER CLASH — an original card duel for the browser. Face the rival duelist Kael across the aether table: pick a card from your hand of five, watch his answer flip over, and let the rotating trump suit decide the clash. Win by the rank gap to burn his Life away, ride an Ember for extra burn, ride a Wave to mend your own Life, and sweep the spoils pile when a clash ties. First duelist to 0 Life falls. No build step, no network: plain static files and a canvas.

## Run it

```sh
node serve.ts   # then open http://localhost:8080
```
